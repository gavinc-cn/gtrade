Core Features

Built for professional quantitative trading

面向专业量化交易的完整功能矩阵

⚡

Ultra-Low Latency Engine

C++17 message-driven architecture with lock-free shared memory IPC. SIMD-accelerated JSON parsing via sonic_json.

C++17 消息驱动架构 + 无锁共享内存 IPC，SIMD 加速 JSON 解析，关键路径亚微秒级延迟

⚙

3-Tier Strategy Isolation

Unified IStrategyProxy interface supporting in-process, subprocess (shared memory ring buffer), and remote (ZMQ) deployment.

统一 IStrategyProxy 接口，支持进程内、子进程、远程三种部署模式，按需平衡延迟与安全

🚀

High Availability

Primary/Standby auto-failover, shared memory WAL ring buffer (<1μs write), periodic snapshots, anti-brain-split Term mechanism.

主备自动切换，共享内存 WAL 环缓冲区（写入延迟 <1μs），定期快照恢复，防脑裂 Term 机制

📈

Professional Backtesting

CSV replay with orderbook simulation mode. Adjustable speed, zero code change between live and backtest.

CSV 历史数据回放，支持 Orderbook 撮合模拟，可调速度，策略代码零修改切换实盘/回测

🔌

Dynamic Plugin System

Strategies compiled as .so shared libraries, runtime dlopen hot-loading, self-registering factory pattern, CMake macro one-click build.

策略编译为 .so 共享库，运行时 dlopen 热加载，自注册工厂模式，CMake 宏一键构建

🤖

AI-Native Integration

MCP protocol integration with AI assistants. Natural language strategy management, AI code generation, AutoResearch pipeline.

通过 MCP 协议与 AI 深度集成，自然语言管理策略、AI 代码生成、AutoResearch 自动研究流水线
